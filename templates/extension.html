📦 Hướng Dẫn Cài Đặt

1

Tải Extension

Click nút "Tải Extension" ở trên để tải file .zip

2

Giải Nén

Giải nén file zip vào một thư mục trên máy tính

3

Mở Chrome Extensions

Vào chrome://extensions hoặc Menu → Extensions → Manage Extensions

4

Bật Developer Mode

Bật công tắc "Developer mode" ở góc trên bên phải

5

Load Extension

Click "Load unpacked" và chọn thư mục đã giải nén

6

Done! 🎉

Extension đã sẵn sàng sử dụng. Mở onluyen.vn và bắt đầu!

🚀 Cách Sử Dụng

1️⃣ Đăng Nhập Gemini

Mở extension popup và click "Đăng nhập Gemini" (hoặc nhập API Key nếu có)

2️⃣ Vào Bài Quiz

Truy cập app.onluyen.vn và mở bài quiz bất kỳ

3️⃣ Bấm Start

Mở popup extension và click nút "BẮT ĐẦU GIẢI" - Extension sẽ tự động làm hết!

❓ Câu Hỏi Thường Gặp

Extension có miễn phí không?

Có! Bạn có thể dùng Gemini Web hoàn toàn miễn phí (cần đăng nhập tài khoản Google). Hoặc dùng Gemini API Key của riêng bạn.

Extension có hoạt động với tất cả các quiz không?

Extension được thiết kế cho app.onluyen.vn. Hỗ trợ câu hỏi trắc nghiệm, đúng/sai, và trả lời ngắn.

Làm sao để cập nhật extension?

Extension tự động kiểm tra phiên bản mới. Khi có update, bạn sẽ thấy banner thông báo trong popup.

Có an toàn không?

Extension chạy hoàn toàn local trên máy bạn. Không thu thập dữ liệu cá nhân.
